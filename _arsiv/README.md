# _arsiv

Terk edilen tasarım, kod, doküman ve varlıkların karantinası. Buradaki hiçbir şey geçerli değildir.

- Claude buradan okumaz, kopyalamaz, örnek almaz, import etmez. Kullanıcı açıkça bir klasörü isterse istisna.
- Her taşıma kendi klasörüne: `_arsiv/YYYY-MM-kisa-ad/` + içinde `NEDEN.md` (ne, neden bırakıldı, yerine ne geldi, ilgili K-no).
- Taşıma = tek commit: dosyalar + KARARLAR satırı + KANONIK güncellemesi.
- Büyük binary'ler (PSD, video) burada tutulmaz: `git tag arsiv/YYYY-MM-ad` at, sonra sil; geri lazım olursa tag'den alınır.
