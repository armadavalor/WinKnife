# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, critique code rather than people,
and keep discussions on topic. Harassment, personal attacks and discriminatory
language are not accepted in issues, pull requests or any other project space.

Report unacceptable behaviour privately through the maintainer's GitHub profile
or a private security advisory if it involves sensitive information. Maintainers
may remove content and block participants who violate this code.
